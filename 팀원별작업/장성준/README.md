## 팀 검토 필요

팀의 `공통규칙.md`는 유지했다. 단, 신규로 제안한 **조회 엔드포인트·응답 세부 필드·오류 코드 번호**, 그리고 **로그인 URL 및 예약 생성 성공 상태**는 다른 팀원의 최종 명세가 확인되지 않아 **잠정안**이다. 다른 팀원의 최종 제출물과 통합할 때 조정해야 한다.

> 문서와 다이어그램은 **설계 명세**로 작성한 것이며 실제 서버 구현 또는 통신 시험이 완료되었다는 뜻은 아니다.
