## 적용한 팀 명세

- HTTPS/TCP 443, HTTP/1.1, JSON UTF-8, 응답 `resultCode`/`message`/`data` 구조: **공통규칙.md**.
- 인증 오류 `1004 INVALID_TOKEN`, 잘못된 입력 `1001 INVALID_REQUEST`, 서버 오류 `9001 INTERNAL_SERVER_ERROR`: **김세훈 담당 명세**.
- 예약 생성 `201 Created` 및 충돌 `3003 SPACE_ALREADY_RESERVED`: **김세훈 담당 명세**.
- 예약 조회의 `spaceId` 예시는 김세훈 예약 생성 문서에 맞춰 **UUID**로 표기했다.

## 팀 통합 시 확인할 사항 (확정된 요구사항으로 오인하지 말 것)

1. 공통규칙의 `spaceId: "A-101"` 예시와 예약 생성 명세의 UUID 예시 중 **어느 방식을 팀 전체가 사용**할 것인지. 본 문서는 UUID를 임시 기준으로 작성했다.
2. 예약 생성 담당자가 **`carNumber` 필수 여부**와 **`expiresAt`의 정확한 의미**를 합의해야 한다. 본 조회 설계는 두 필드를 정의하되, 차량번호 미입력 시 `null`을 허용하는 **제안안**이다.
3. 예약 상태(`RESERVED` 등), 예약 조회 전용 오류 `3010`·`3011`, 조회 API 경로 및 권한 오류 시 `403` 대 `404` 정책은 팀 최종 합의가 필요하다.
4. 회원가입의 세부 API·JSON 명세는 팀에서 미정이므로 절차 개요만 포함했다. 로그인 및 예약 생성은 인증 담당자 명세를 참조한다.
5. 팀의 `공통규칙.md`의 `2002 SPACE_ALREADY_RESERVED` 예시는 김세훈의 예약 생성 명세 `3003`과 충돌하므로 팀 공통규칙도 최종 수정해야 한다. 이 ZIP은 **장성준 개인 폴더용 파일만** 담는다.

> 본 자료는 통신 프로토콜 **설계 명세**다. 서버 구현·통신 시험을 완료했다는 의미는 아니다. `.drawio` 파일은 사용자가 제거한 상태를 반영해 압축본에도 포함하지 않았다.
