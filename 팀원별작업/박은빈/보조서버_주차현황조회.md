# 보조 서버 주차 현황 조회

층별 빈자리, 주차 가능 구역, 전기차 충전 구역 현황을 짧은 주기로 빠르게 갱신하기 위해 보조서버에 호출한다.


<br>

## UDP 애플리케이션 헤더

UDP 표준 헤더(8바이트) 뒤에 6개 필드로 구성된 12바이트 애플리케이션 헤더를 부착한다.


<br>

오프셋 | 필드명 | 값 형식 / 최대 크기 | 설명
| --- | --- | --- | --- |
0 ~ 1 | magicNumber | uint16 / 2바이트 | 프로토콜 식별용 고정값 (0x504B)
2 | messageType | uint8 / 1바이트 | 메시지 종류 구분 (0x01: 조회 요청, 0x02: 조회 응답)
3 | reserved | uint8 / 1바이트 | 4바이트 메모리 정렬용 예비 필드 (0x00 고정)
4 ~ 7 | requestId | uint32 / 4바이트 | 요청과 응답을 1:1로 연결하는 고유 식별 번호 (예: 1001)
8 ~ 9 | sequenceNumber | uint16 / 2바이트 | 최신 현황 구분 순번 (요청 시 0, 서버 응답 시마다 1씩 증가)
10 ~ 11 | payloadLength | uint16 / 2바이트 | 뒤에 이어지는 JSON 페이로드의 UTF-8 바이트 길이 (최대 1024)


<br>
<br>


## 주차 현황 조회 요청

조회 요청 시 messageType은 0x01, sequenceNumber는 0으로 설정하며, JSON 페이로드에는 조회 대상 층 정보만 담아 전송한다.


<br>

**요청 예시**
```
magicNumber=0x504B | messageType=0x01 | reserved=0x00 | requestId=1001 | sequenceNumber=0 | payloadLength=19
{
  "floor": "B1"
}
```


<br>
<br>


## 주차 현황 조회 응답

응답 시 messageType은 0x02로 설정하며, 요청에서 받은 requestId를 그대로 반환하고 서버의 최신 순번(sequenceNumber)을 헤더에 담아 전송한다.


<br>

필드명 | 값 형식 / 최대 크기 | 설명
| --- | --- | --- |
resultCode | 정수 / 4바이트 | 처리 결과를 나타내는 코드 (정상 처리 시 0)
message | 문자열 / 최대 64바이트 | 결과 영문 이름
data | 객체 또는 null | 성공 시 주차 현황, 실패 시 null
floor | 문자열 / 최대 10바이트 | 해당 층
availableCount | 정수 / 4바이트 | 현재 주차 가능 구역 수 
availableSpaces | 문자열 배열 / 각 최대 16바이트 | 현재 주차 가능 구역 ID 목록
evChargingZones | 객체 배열 | 전기차 충전 구역 현황 목록
chargerId | 문자열 / 최대 16바이트 | 전기차 충전 구역 ID
status | 문자열 / 최대 20바이트 | 충전기 상태 (AVAILABLE, IN_USE, OUT_OF_ORDER)


<br>

**성공 응답 예시**
```
magicNumber=0x504B | messageType=0x02 | reserved=0x00 | requestId=1001 | sequenceNumber=42 | payloadLength=288
{
  "resultCode": 0,
  "message": "SUCCESS",
  "data": {
    "floor": "B1",
    "availableCount": 2,
    "availableSpaces": ["B1-01", "B1-02"],
    "evChargingZones": [
      {"chargerId": "EV-B1-01", "status": "AVAILABLE"},
      {"chargerId": "EV-B1-02", "status": "IN_USE"}
    ]
  }
}
```


<br>

**실패 응답 예시**
```
magicNumber=0x504B | messageType=0x02 | reserved=0x00 | requestId=1002 | sequenceNumber=43 | payloadLength=70
{
  "resultCode": 2001,
  "message": "INVALID_FLOOR",
  "data": null
}
```
